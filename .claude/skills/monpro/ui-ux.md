# MONPRO UI/UX

Brand:
MONPRO

Positioning:
A trusted way to find and book service professionals.

Design:
- modern
- clean
- premium
- practical
- Côte d’Ivoire-first
- scalable to Africa

Core UX principle:
A user should be able to go from “I need a service” to “I have booked a professional” with minimal friction.

Every screen should define:
- loading
- empty
- error
- success
- disabled
- permission-denied states where relevant

Avoid:
- excessive gradients
- unnecessary animations
- dense forms
- hidden primary actions
- fake statistics
- fake reviews
- decorative UI that slows task completion

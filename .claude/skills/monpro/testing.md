# MONPRO Testing

Critical workflows must have automated tests.

Unit:
- matching score
- commission calculation
- status transitions
- validation
- permissions

Integration:
- auth
- request lifecycle
- quote lifecycle
- booking lifecycle
- review constraints
- payment lifecycle
- webhook idempotency

Security:
- unauthorized resource access
- role escalation
- IDOR
- invalid state transitions

Run tests before declaring work complete.
